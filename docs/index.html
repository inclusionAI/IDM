01 THE CENTRAL IDEA核心思路

The generator can
also be the representation.生成器，
也可以提供表征。

IDM augments internal DMD with feature-moment matching. Its EMA copy supplies a shared feature space for generated and reference samples.IDM 在内部 DMD 之上加入特征矩匹配。生成器的 EMA 副本为生成样本和参考样本提供共同的特征空间。

A score points toward increasing log density. DMD uses the difference between the reference and generated scores to guide samples toward a lower model-to-reference density ratio.Score 指向对数密度增加的方向。DMD 使用参考分布与生成分布的 score 差，引导样本朝模型与参考密度比降低的方向移动。

Classical DMD uses a pretrained teacher for the reference score and learns a separate fake-score network for the changing generated distribution.经典 DMD 用预训练教师提供参考 score，并训练独立的 fake-score 网络来跟踪不断变化的生成分布。

Following APEX, the same network uses opposite condition vectors to select its reference and model velocity branches. Their difference estimates the DMD correction without a separate fake-score network.沿用 APEX，同一网络用相反的条件向量区分参考速度分支和模型速度分支。两者之差提供 DMD 校正的估计，无需独立的 fake-score 网络。

The interpretation assumes both branches approximate their marginal velocities.这一解释以两个分支能近似相应边缘速度为前提。

IDM keeps the full DMD correction and compares pooled feature statistics across generated and reference samples. The generator’s EMA copy supplies those features.IDM 保留完整 DMD 校正，并比较生成样本与参考样本的汇总特征统计量。这些特征由生成器自身的 EMA 副本提供。

Within an update, EMA parameters are fixed; gradients still pass through the feature network to current generated samples.单次更新中，EMA 参数固定；梯度仍可经过特征网络传回当前生成样本。

02 WHY MOMENTS?为什么约束矩？

A full field.
Two components.完整的场，
两部分结构。

DMD already contains moment information. The decomposition reveals a part determined by means and covariances—and what remains beyond it.DMD 本身已经包含矩信息。分解揭示了由均值、协方差决定的部分，以及它们之外仍然存在的 score 结构。

Eq. 7 · EXACT DECOMPOSITION, AT FIXED CONDITION固定条件下的精确分解

Means and covariances均值与协方差

The difference between the scores of moment-matched Gaussians. If both moments match in the same coordinate space, this component vanishes.由矩匹配高斯的 score 差构成。在同一坐标空间中，均值和协方差相同，这一分量就消失。

Non-Gaussian residual非高斯残差

The remaining score structure. Equal means and covariances do not guarantee equal distributions, so the residual can still be nonzero.高斯近似之外的 score 结构。均值和协方差一致并不保证两个分布一致，因此残差仍可能非零。

↳

IDM keeps the full DMD correction and adds a feature-space moment loss. The added loss is motivated by this decomposition; it does not estimate the sample-space Gaussian or residual component.IDM 保留完整 DMD 校正，再加入特征空间的矩损失。分解为该约束提供动机，但新增损失并不估计样本空间中的高斯分量或残差分量。

The score decomposition behind Eq. 7展开 Eq. 7 背后的 score 分解+

For a smooth positive density with finite second moment and positive-definite covariance, its moment-matched Gaussian is对具有有限二阶矩、正定协方差的光滑正密度，其矩匹配高斯为 .

The Gaussian is an analytical approximation to the score; generated samples are not assumed to be Gaussian. Each residual is orthogonal to constant and linear functions under its own distribution, under the paper’s regularity conditions. The difference of two residuals need not inherit that orthogonality.高斯用于分析 score，并不假设生成样本服从高斯分布。在原文正则条件下，每个残差在自身分布下与常数及线性函数正交；两个残差之差不必继承这一正交性。
